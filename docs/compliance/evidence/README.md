# Compliance Evidence

This directory stores generated and manually collected evidence from
security and compliance validation performed across the homelab.

Planned evidence includes:

- firewall configuration
- SSH configuration
- sudo policy
- auditd configuration
- SELinux status
- AppArmor status
- service validation
- package state
- centralized logging validation
- PostgreSQL access controls
- Ansible validation output
- future OpenSCAP reports

Sensitive information, private SSH keys, passwords, tokens and other
credentials must never be stored in this directory.
